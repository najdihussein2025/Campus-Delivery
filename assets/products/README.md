# Product images

One square photo per product, named after the product id in `src/data/campus.json`.

- Size: **600 × 600 px**, JPG, **under 80 KB** each.
- Then add one line per file in `src/data/images.js`, e.g. `p12: require('../../assets/products/p12.jpg'),` (Metro needs static `require`s).
- Products without a file keep the gradient + icon tile. Nothing crashes.
