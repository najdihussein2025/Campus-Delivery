# Store logos

One square logo per store, named after the store id in `src/data/campus.json`.

- Size: **300 × 300 px** (or 600 × 600), JPG or PNG (then use the `.png` name in `images.js`), **under 80 KB**.
- Add one line per file in `src/data/images.js` under `storeLogos`, e.g. `cafeteria: require('../../assets/stores/cafeteria.jpg'),`.
- Stores without a file keep the gradient + icon tile.

| File | Store |
| --- | --- |
| `cafeteria.jpg` | UA Cafeteria |
| `coffee.jpg` | Coffee Corner |
| `bookstore.jpg` | Bookstore & Stationery |
| `printing.jpg` | Printing Office |
